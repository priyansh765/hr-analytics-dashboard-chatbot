# hr-analytics-dashboard-chatbot
HR Analytics Dashboard with AI Chatbot
## Dashboard Structure

### Pages
1. **Overview** — Key HR metrics at a glance
2. **Attrition Analysis** — Deep dive into attrition patterns
3. **Department Insights** — Department and role-level analysis
4. **Attrition Prediction** — ML-based risk prediction
5. **HR Chatbot** — AI assistant for HR queries

### Filters
- Department
- Gender
- Age Range
- Attrition Status
